# RTX 5090 PCA benchmark report

RTX 5090, Windows WDDM, driver 616.92, CUDA 13.4.59, Release SM120. Base revision 58985bb plus benchmark-local PCA additions. Five Google Benchmark repetitions; each event measurement averages 100 complete CUDA Graph replays. Setup, transfers, runtime compilation, tuning, and validation are excluded.

| Pipeline | Median (us/window) | Standard deviation (us) | Output |
|---|---:|---:|---|
| PCA/FP32 | 105.939 | 0.522 | FP32 |
| PCA/U8_Fused_FP16_Autotuned | 98.581 | 0.047 | FP16 |
| PCA/U8_to_FP32 | 115.845 | 0.057 | FP32 |

Direct-U8 speedups: 1.075x versus PCA/FP32, 1.175x versus PCA/U8_to_FP32.

Selected configuration: FP16 output K=512 M=256 threads=256/256.

The FP16-output path changes output precision and bandwidth. Production FP32-storage PCA already permits tensor-core FP16 computation. These timings do not isolate input conversion from all other implementation differences.

The direct path uses CUTLASS tensor-core GEMMs with fused U8-to-half tile loads, FP32 split-K Gram reduction, an NVRTC-compiled FP32 cuSolverDx eigensolve, and FP16 projected output. Gram scaling is an exact power of two. Zero matrices use an identity eigenbasis; vendor nonconvergence uses a native, bounded FP32 fallback, including a closed-form rank-one solution. All required launches are included in timing.

The dedicated correctness test passed all 36 configurations on six primary inputs plus one correlated stress case. Checks include FP64 Gram/reference agreement, orthogonality, solver residuals, selected subspace and sign-aligned projections on separated spectra, projection against the actual basis for degenerate spectra, exact zero, bit-identical replay, and unchanged U8 input. Acceptance thresholds are 1%; near-zero selected output uses input-energy normalization.

Reproduce:

```powershell
cmake --preset msvc-multi -DPCA_BENCH_CUDA_ARCH=120
cmake --build --preset build-Release
./build/msvc-multi/Release/pca_bench.exe --benchmark_min_time=0.01s --benchmark_repetitions=5 --benchmark_report_aggregates_only=true --benchmark_out=build/pca-google.json --benchmark_out_format=json
```
