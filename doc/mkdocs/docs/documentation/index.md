# Documentation

This section explains how to use and extend the software in the Holoflow project. Choose the layer that matches the work you want to do.

<div class="grid cards" markdown>

-   **Holovibes**

    Operate the reference desktop application for acquisition, processing, visualization, and recording.

    [Read the Holovibes documentation](../holovibes/index.md)

-   **Holoflow**

    Understand the graph model, runtime architecture, task authoring, scheduling, and inspection facilities.

    [Read the Holoflow documentation](../holoflow/index.md)

-   **Curaii**

    Work with the low-level RAII abstractions used to manage CUDA and companion-library resources.

    [Read the Curaii documentation](../curaii/index.md)

-   **Holofile**

    Read and write high-throughput holographic recordings in the `.holo` format.

    [Read the Holofile documentation](../holofile/index.md)

</div>

For exact task behavior and accepted settings, use the [Reference](../reference/index.md) section. For experiment-oriented procedures, start with [Applications](../applications/index.md).
